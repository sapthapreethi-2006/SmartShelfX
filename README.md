# 📦 SmartShelfX - Inventory Management System
## 📖 About

SmartShelfX is a full-stack Inventory Management System developed during the Infosys Internship. The application helps organizations efficiently manage inventory, products, vendors, and stock records through a centralized dashboard. It provides secure authentication and role-based access to simplify inventory operations.
## 🎯 Objectives

- Simplify inventory management
- Maintain product records
- Track stock efficiently
- Improve inventory accuracy
- Reduce manual data entry
- ## ✨ Features

- Product Management
- Inventory Tracking
- SKU Management
- Vendor Management
- Stock Updates
- Dashboard
- Search Products
- CRUD Operations
- Role-Based Access

- ## 🔑 Authentication

The application uses JWT authentication to secure APIs and provide role-based access for authorized users.
## 📦 Inventory Modules

- Products
- Inventory
- Vendors
- Categories
- Stock Management
- ## 🏗 System Architecture

The application follows a three-tier architecture with React.js as the frontend, Spring Boot as the backend, and MySQL as the database. REST APIs are used for communication between the frontend and backend.

## ⚙ Installation

1. Clone the repository.
2. Configure MySQL.
3. Update application.properties.
4. Run the Spring Boot backend.
5. Start the React frontend.
