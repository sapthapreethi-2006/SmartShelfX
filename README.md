# 📦 SmartShelfX - Inventory Management System
## 📖 About

SmartShelfX is a full-stack Inventory Management System developed during the Infosys Internship. The application helps organizations efficiently manage inventory, products, vendors, and stock records through a centralized dashboard. It provides secure authentication and role-based access to simplify inventory operations.
## 🎯 Objectives

- Simplify inventory management
- Maintain product records
- Track stock efficiently
- Improve inventory accuracy
- Reduce manual data entry
